# Focus 工作台 · 离线 Qwen 4B / 9B

版本：1.1.0。本地 AI 集成在现有安卓 App 内，保留任务、目标、统计、备份和高刷新率适配。

提供 **Qwen3.5-4B 快速档**与 **Qwen3.5-9B 高质量档**，每次只加载一个模型。使用 APK 内的 llama.cpp 原生 CPU 引擎，不需要安装 Ollama、Termux 或连接 Mac。推理不使用外部网络，APK 继续没有 Internet 权限。

浏览器版可以查看模型说明，基础工作台正常使用；本地推理只在 Android 安装包中启用，不会自动改用云端模型。GPU / NPU 尚未接入。

## 现在可以做什么

- 在「本地 AI」选择 4B / 9B，导入、加载、释放或删除模型。
- 中文问答、逐步显示回复、停止生成；临时对话可清空。
- 可选附带今日最多八条任务与容量摘要；关闭后只提供项目、日期和时区等必要信息。
- 将一句话整理成一至三个任务草稿，编辑项目、日期、预计用时、优先级和开始时间，确认后批量保存。
- 不直接删除、完成或结转任务，不修改保护时段和容量设置。Goal / Milestone 自动创建、文档检索、图片与语音暂未实现。

## 在 vivo 上使用

1. 安装或覆盖升级 1.1.0 APK，进入左侧导航的「本地 AI」。
2. 选择「快速 · 4B」或「高质量 · 9B」。
3. 已预置模型的设备会显示「已导入，加载时校验」或「文件校验通过」。未导入时，用「获取文件」在手机浏览器打开固定版本下载页，再选择「导入模型」。
4. 点击「加载」，或直接输入问题后点击「加载并发送」。第一次加载包含文件校验，可能比后续慢。
5. 使用「问一问」聊天；切换「生成任务」可生成草稿。检查默认日期、DDL 和时长，再点击「确认加入工作台」。

如果草稿生成后工作台数据变化，需要重新核对后再保存。错误日期、未知项目和受保护时段冲突会阻止写入。未明确的日期和预计用时可能使用模型提示中的默认值，需人工核对。

进入后台会取消生成并释放模型；前台空闲约 60 秒后自动释放。处理模型或生成时保持屏幕亮起，结束后恢复系统休眠行为；没有后台唤醒锁或常驻服务。停止按钮取消实际计算，已生成文本保留，未确认的任务不会写入。

## 支持的模型文件

首版只接受下表固定版本、固定大小与 SHA-256 的文件。不能将其他同名模型、其他精度或视觉投影文件当作兼容模型导入。

| 模型 | 精度 | 文件大小 | 来源 |
| --- | --- | --- | --- |
| Qwen3.5-4B | Q4_K_M | 2,740,937,888 bytes | [固定版本文件](https://huggingface.co/unsloth/Qwen3.5-4B-GGUF/blob/e87f176479d0855a907a41277aca2f8ee7a09523/Qwen3.5-4B-Q4_K_M.gguf) |
| Qwen3.5-9B | Q4_K_M | 5,680,522,464 bytes | [固定版本文件](https://huggingface.co/unsloth/Qwen3.5-9B-GGUF/blob/3885219b6810b007914f3a7950a8d1b469d598a5/Qwen3.5-9B-Q4_K_M.gguf) |

4B SHA-256：

```text
00fe7986ff5f6b463e62455821146049db6f9313603938a70800d1fb69ef11a4
```

9B SHA-256：

```text
03b74727a860a56338e042c4420bb3f04b2fec5734175f4cb9fa853daf52b7e8
```

权重由 Unsloth 量化发布，原模型为 Qwen，采用 Apache-2.0。权威目录为项目的 `public/ai-models.json`，前端与原生端读取同一份目录。APK 不包含数 GB 权重；两个文件合计约 8.42 GB。导入采用有界缓冲、完整摘要校验和原子替换，失败保留已有有效模型。

导入时至少预留“模型文件大小 + 256 MB”的可用空间，手机外部下载目录中保留的源文件另占空间。模型存储不做 Ollama 注册，因此没有额外的 Ollama 权重副本。模型大小不等于运行内存；9B 内存不足时请关闭其他应用或使用 4B。

## 模型、任务与对话的保存

模型放在应用私有文件目录，校验元信息独立保存。任务仍使用现有 SharedPreferences 仓储，主数据格式未因 AI 改写。

- 删除模型不删除任务；清空计划不删除模型。
- 任务 JSON 导出不包含模型和 AI 对话。
- 对话只保留在当前页面会话中，重启/刷新后清空；不是长期聊天历史。
- 同包名、同签名的覆盖安装保留任务和模型；卸载/清除应用数据会删除它们。
- 原生插件没有任务存储写入接口。模型草稿经过 Zod、现有领域规则和用户确认后，才通过 DashboardRepository 保存。

## 默认配置与使用边界

| 配置 | 当前行为 |
| --- | --- |
| 引擎 | llama.cpp JNI，固定源码提交 |
| 后端 | CPU，4 线程，运行时选择兼容的 ARM 指令实现 |
| 模型 | 4B 默认；9B 手动选择；只驻留一个 |
| 上下文 | 4096 tokens，包含输入和输出 |
| 输出 | 问答最多 512 tokens；任务草稿最多 768 tokens |
| 非思考模式 | 使用固定 Qwen3.5 模板的非思考生成后缀 |
| 任务格式 | JSON grammar 约束语法，再校验字段与业务规则 |
| 超时 | 原生模型加载和生成各设约 120 秒上限；文件校验单独执行，可取消 |
| 流式更新 | 原生合并约 80 ms 更新，只刷新 AI 面板 |
| 后台/空闲 | 后台取消并释放；前台空闲约 60 秒释放 |

只附带有限的相关上下文，不能当作完整任务数据库查询。长输入会提示超出上下文，需要缩短或减少任务。模型可能误解日期、项目和优先级；结构化格式正确不代表内容正确。完成率、图表、容量与 20:00–23:00 保护时段仍由现有代码计算和验证。

120 Hz 显示请求保留。推理时真实流畅度受 CPU、温度和内存影响，不承诺所有场景持续 120 FPS。

## 从源码构建

安装 Node.js 22+、JDK 21、Android Studio，以及：

```bash
sdkmanager "platforms;android-36" "build-tools;36.0.0" "ndk;28.2.13676358" "cmake;3.22.1"
```

也可以在 Android Studio 的 SDK Manager 中选择对应版本。项目仍 target SDK 36，首版 APK 构建 arm64-v8a。原生 AI 检查 Android 8 / API 26+；基础 App min SDK 保持 24。

在项目根目录：

```bash
npm ci
npm run android:apk
```

第一次原生构建下载校验固定的 llama.cpp 源码，并获取其固定的 KleidiAI 依赖；后续复用 `.native/` 缓存。生成 `releases/focus-dashboard-debug.apk`。模型运行不需要构建时的网络。

修改网页后，运行 `npm run android:sync`，再从 Android Studio 的 `android/` 工程运行。只在 Android Studio 点击 Run 不会更新网页源文件。

## USB 预置模型（开发用）

已安装 debug APK、已授权设备、Mac 上已有两个指定模型文件时，可直接传入 App 私有目录：

```bash
node scripts/provision-ai-models.mjs --serial YOUR_DEVICE_SERIAL --models-dir /absolute/path/to/models
```

可选 `--models 4b` 或 `--models 9b`。脚本先校验主机文件，通过 ADB 传输并检查大小；第一次应用加载时再校验手机文件 SHA-256。此操作会停止并重开工作台，不修改任务存储，仅适用于允许 run-as 的 debug APK。手机需要为临时文件和最终副本预留空间；中断时可重试，清理本次命名的临时模型文件。

日常用户使用 App 内系统文件选择器导入；正式签名版本不依赖 USB 预置工具。

## 测试

```bash
npm run typecheck
npm test
npm run build
npm run test:e2e
```

AI 领域测试覆盖草稿与数据分离、伪造字段、引用、日期、保护时段、时区、上下文筛选和控制 token 转义。浏览器原生接口桩测试覆盖模型选择、流式回复、取消与过期事件、草稿预览/修改/保存；这些桩不代表模型推理测试。

明确指定已授权真机、安装 debug APK 并把应用保持前台后，可执行真实模型只读测试：

```bash
node scripts/test-android-ai.mjs --serial YOUR_DEVICE_SERIAL --models 4b,9b
node scripts/test-android-scroll.mjs --serial YOUR_DEVICE_SERIAL
node scripts/test-android-refresh.mjs --serial YOUR_DEVICE_SERIAL
```

AI 脚本要求模型已导入/预置，执行中文问答、JSON 草稿、取消和单模型状态检查，比较任务数据摘要；不会将生成内容保存为任务。只将合成问题用于日志。不要运行仅限模拟器的旧数据改写测试脚本来验证个人手机。

实际通过项与性能记录见 [验证记录](../VALIDATION.md)。未执行的长期发热、GPU/NPU 或其他机型测试不视为通过。
