# Focus 工作台 1.1.0

本地运行的个人工作仪表盘，支持 Mac 浏览器与安卓安装包。安卓包安装后不依赖 Mac 或网页服务器。

## 功能

- 每日/每周/每月任务、Goal → Milestone → Task 关联、进度与图表。
- DDL、优先级、预计/实际用时、容量预警、未完成任务结转和 JSON 备份。
- 可编辑的六个项目类别，默认保护 20:00–23:00 的健身与 CS2 时段。
- 安卓本地 Qwen3.5 4B / 9B，模型导入与校验、离线问答、流式输出、停止计算。
- AI 生成任务草稿，可编辑并确认后加入工作台，继续执行保护时段和引用校验。
- 安卓持久化、独立滚动容器与最高 120 Hz 刷新率请求。

## 安装与升级

APK 为供本地安装的 debug 版本。已有用户请先导出任务备份，再使用同签名 APK 覆盖升级；无需卸载。自行构建或 GitHub Actions 的 debug 签名可能与原安装不同，无法直接覆盖时应先做好备份，不要直接卸载。

模型权重不随 APK 或仓库分发。按 [本地 AI 指南](local-ai/README.md) 获取指定的 Q4_K_M 文件：4B 约 2.74 GB，9B 约 5.68 GB。源码构建参见 [主 README](../README.md)。

## 验证与边界

已有 23 项领域/仓储/AI 测试和 24 项桌面/手机浏览器操作测试。vivo X Fold5 完成两个模型的真实问答、JSON 生成和取消测试；任务草稿审核、后台释放、滚动与刷新率另有真机检查。具体方法、性能数据及未验证范围见 [验证记录](VALIDATION.md)。

当前推理仅使用 CPU；GPU/NPU、长期发热与耗电尚未验证。浏览器版没有模型推理。没有账号、自动跨设备同步、后台提醒或 Play 商店分发。对话为临时会话；模型可能误解日期与项目，保存任务前需要核对。
